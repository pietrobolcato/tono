# Tono v0.66.1-opt

Turning MASTER on any layer edit page adjusts the layer in focus and briefly shows its gain at the bottom of the screen. This also works on the Envelope, LFO, Pattern, FX, and EQ pages.

Studio Dark is first in the theme list and the default for a fresh setup, followed by Studio Light and Dial. Existing firmware settings retain the saved theme.
