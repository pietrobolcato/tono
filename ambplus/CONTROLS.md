# AMB+ v0.5 control card

The playable instrument is the real `.fwsc` package in Joakim Eriksson's FM1 hardware emulator. The handoff HTML is a visual specification. Use one sounding instance at low volume; preserve unsaved emulator work before switching packages.

- HOME SELECT: MASTER → L1 → L2 → L3 → L4. Four sound layers; MASTER adds no voice. MASTER pot always controls the last HOME target, on every page. Cross its saved level to pick it up after retargeting.
- HOME knobs: displayed performance macros, bounded offsets from deep baselines. Pad/Drone knob 3 is SUSTAIN, affecting envelope, hold length and generated activity. New factory Pad/Drone patches have sustained envelopes and 84% base activity. Existing user envelopes are retained.
- HOME keyboard: shared pitch-class pool. Bright keys are chord tones, softer lights are available pool notes. Tap to add/remove classes for generation; tonic stays and at least three classes remain. A stock scale replaces the custom pool; key transposes it. EDIT's keyboard can otherwise audition literal/off-scale notes, except on PATTERN or while its sound is being replaced.
- EDIT opens the selected layer (MASTER opens GLO MASTER FX). Seven pages: MODE, SOUND, ENVELOPE, LFO, PATTERN, FX, LAYER EQ. Physical **SCL** is the handoff's **SEL** page button.
- MODE ALGORITHM previews one of seven roles; REC commits. Turning ALGORITHM alone is silent. EDIT again proposes restoring this track to its last loaded sound, macros, pattern, level and layer EQ; REC confirms, HOME cancels. Other layers and global settings remain.
- SOUND SELECT chooses a patch destination. EDIT toggles PATCH/DETAIL; DETAIL SELECT cycles ENGINE/FILTER/PLAY. Ordinary parameter knobs remain direct. SAMPLE SELECT on SOURCE chooses one of two original read-only PCM examples; EDIT cycles SOURCE/PLAYBACK/CHARACTER. No external capture is simulated.
- Patch, sample-source, role, restore and piece-recall replacements let the old engine finish its release before installing the destination. **GLO / HARMONY / knob 4 = TAIL CAP**, 250–6000 ms in 250 ms steps, default 3000 ms. Only slower releases are accelerated to fit the cap; shorter ones are not lengthened. The new sound then uses its own envelope with no added incoming fade. Shared FX buffers continue. Rapid selections coalesce without restarting the release. Footer status shows OLD SOUND RELEASING / NEXT QUEUED. Edits to a queued sound apply when it starts. Existing realtime overload protection can still shorten tails under stress.
- HARMONY's former global GLIDE shortcut is replaced by TAIL CAP. Individual GLIDE remains in SOUND/DETAIL/PLAY. AUTO, HOME chord commits, key/scale/pool changes and GENERATE styles continue through normal note attacks/releases/common-tone holds, with no extra musical source-volume envelope or forced generator pitch slide.
- HOME or GLO EVOLVE ALGORITHM proposes a compatible chord degree. REC commits immediately while stopped or at the next bar during PLAY. It does not change tonic/key. EVOLVE SELECT chooses OFF/1/2/4/8/16/32/64 automatic bars. The seeded degree bag avoids immediate/A–B–A repeats; eight PHRASES also vary Pad motifs and six voicing pairs.
- GLO GENERATE knobs 1–3 choose 8 rhythms, 8 phrases, 6 interplay policies after a 90 ms final settle. Knob 4 sets variation. During PLAY, style changes queue together to the four-bar grid; choosing the active style cancels its pending change. SELECT, ALGORITHM and REC are inert here. Manual notes/patches remain literal.
- LFO dot follows the real DSP phase, at the chosen frequency/shape; S&H uses its actual held value. Fast oscillation is sampled at display refresh. FX graphics show the actual send/routing or a control-response diagram, not an audio meter or measured spectrum.
- PATTERN REC captures the generated pitched 16-slot phrase and arms **silent selected-step entry**. SELECT chooses an edit slot; keys write that slot and advance the cursor. Entry never auditions immediately, stopped or playing. The sequencer plays the note on its next scheduled visit. REC stops entry. Existing manual slots remain. The current format stores one note per pitched step; a generated chord contributes its first melody note. Drums use SELECT for lane and white keys for 16 step toggles.
- PATTERN's **amber marker / PLAY number** is the actual layer step, respecting SPEED and swing dispatch, including rests. It is a clock position, not a note-on/audio-level meter; envelopes and echoes sound between steps. The **thin green marker / EDIT number** is the selected entry slot. The page updates at up to 20 Hz. EDIT or SEQ again toggles MANUAL/AUTO without deleting manual edits; toggle back to reuse them. REC from AUTO captures a fresh phrase.
- LAYER EQ is one SCL press after FX. LOW/MID/HIGH/OUTPUT each cover −12…+12 dB. Broad fixed splits are about 180 Hz / 2.3 kHz. Processing precedes dry mix and shared FX sends, including drum image/per-lane sends. Each track has independent state/gains; flat EQ is exact bypass, changes smooth, high boosts have a bounded headroom knee. Master EQ remains separate.
- PRESETS previews six factory pieces then eight user slots. REC recalls at the next bar during PLAY; HOME cancels. Replacing sounding tracks uses the bounded old-release handoff. Recall does not save.
- SAVE: stop playback, SELECT a slot, REC saves an empty slot. Occupied slots need REC twice; SELECT/HOME cancels overwrite. No fabricated date. Failed writes retain the previous CRC-verified A/B copy. Unsupported flash is refused.
- HOME held + SELECT in EDIT changes the edited layer on the same page; the volume target stays at the last HOME choice. HOME + OCT− mutes that target; HOME + OCT+ solos/unsolos it.
- Emulator combinations: hold computer **7** (HOME), then **Z** (OCT−) / **X** (OCT+), or click the corresponding panel button while holding 7. Hold 7 plus left/right for cross-layer editing. The mouse alone holds one control at a time.
- PLAY tap starts/stops; hold 800 ms for emergency output fade. A later tap reopens the output. ENV/LFO/FX/SEQ/ARP are layer shortcuts; OCT± normally shifts keyboard octave. LEDs indicate available actions; pending REC confirmations breathe, recording REC stays solid.
- Interaction guidance is always in the same three-line footer: navigation, context actions, then notices/pickup/status. Matching font, color, uppercase casing and alignment. Page bodies hold data and diagrams; pickup does not hide action hints.

Save **v4 is 1420 bytes**, within the existing 3840-byte A/B capacity and unchanged eight-slot sector bounds. v1–v3 1400-byte records migrate with flat layer EQ and a 3000 ms cap. Older firmware cannot read v4; preserve old pieces/exports for emulator rollback.

The pinned HAL/emulator model knobs 1–4 as quadrature encoders; only MASTER is an absolute ADC pot. No analog wiring or external input was invented. The generic absolute selector decoder remains separately tested.
