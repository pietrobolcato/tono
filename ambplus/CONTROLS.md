# Tono control card

The playable instrument is the real `.fwsc` package in Joakim Eriksson's FM1 hardware emulator. The handoff HTML is a visual specification. Use one sounding instance at low volume; preserve unsaved emulator work before switching packages.

- SELECT browses the current list, including GLO THEME. ALGORITHM opens chord and layer-role proposals. While a proposal is open, SELECT or ALGORITHM browses it, REC confirms and HOME cancels. PRESETS opens the piece list. The four numbered knobs edit the parameters shown on screen.
- HOME SELECT: MASTER → L1 → L2 → L3 → L4. Four sound layers; MASTER adds no voice. MASTER pot always controls the last HOME target, on every page. Cross its saved level to pick it up after retargeting. While changing a selected layer's gain, the top HOME label/value/bar temporarily shows that layer; MASTER returns after 1.2 seconds without an accepted gain change.
- HOME knobs: displayed performance macros, bounded offsets from deep baselines. Pad/Drone knob 3 is SUSTAIN, affecting envelope, hold length and generated activity. New factory Pad/Drone patches have sustained envelopes and 84% base activity. Existing user envelopes are retained.
- HOME keyboard: shared pitch-class pool. Bright keys are chord tones, softer lights are available pool notes. Tap to add/remove classes for generation; tonic stays and at least three classes remain. A stock scale replaces the custom pool; key transposes it. EDIT's keyboard can otherwise audition literal/off-scale notes, except on PATTERN or while its sound is being replaced.
- EDIT opens the selected layer (MASTER opens GLO MASTER FX). Seven pages: MODE, SOUND, ENVELOPE, LFO, PATTERN, FX, LAYER EQ. Physical **SCL** is the handoff's **SEL** page button.
- MODE ALGORITHM previews one of seven roles; REC commits. Turning ALGORITHM alone is silent. EDIT again proposes restoring this track to its last loaded sound, macros, pattern, level and layer EQ; REC confirms, HOME cancels. Other layers and global settings remain.
- SOUND SELECT chooses a patch destination. EDIT toggles PATCH/DETAIL; DETAIL SELECT cycles ENGINE/FILTER/PLAY. Ordinary parameter knobs remain direct. SAMPLE SELECT on SOURCE chooses one of two original read-only PCM examples; EDIT cycles SOURCE/PLAYBACK/CHARACTER. No external capture is simulated.
- Patch, sample-source, role and restore replacements use **GLO / HARMONY / knob 4 = TAIL TIME**, 250–6000 ms in 250 ms steps, default 3000. This now sets the duration for active short and long synth releases. Current amplitude falls smoothly; FM6 internal envelopes are held while oscillators continue. New sounds enter afterward with their own envelope and no extra incoming fade. Already-ended hits/one-shots cannot be stretched from silence. Rapid choices coalesce without restarting the old release. Pending state is shown in the footer; edits to the queued sound apply on arrival. Realtime overload protection can override tails under stress.
- Whole-piece recalls use one coordinated transition: outgoing sources, master, EQ and FX settings remain until release completion; then the destination starts. The existing shared reverb engine may reset its own model buffers when the new piece selects a different effect model. No duplicate master effect is rendered.
- The former global GLIDE shortcut is now TAIL TIME; individual GLIDE remains in SOUND/DETAIL/PLAY. Normal AUTO chords and key/scale/pool edits keep their normal note envelopes/common-tone holds. Explicit queued GENERATE style changes release generated parts at their four-bar boundary; manual patterns remain literal. No generator-imposed pitch slide or automatic per-chord volume fader is added.
- HOME or GLO EVOLVE ALGORITHM proposes a compatible chord degree. REC commits immediately while stopped or at the next bar during PLAY. It does not change tonic/key. EVOLVE SELECT chooses OFF/1/2/4/8/16/32/64 automatic bars. The seeded degree bag avoids immediate/A–B–A repeats; eight PHRASES also vary Pad motifs and six voicing pairs.
- GLO GENERATE knobs 1–3 choose 8 rhythms, 8 phrases, 6 interplay policies after a 90 ms final settle. Knob 4 sets variation. During PLAY, style changes queue together to the four-bar grid; choosing the active style cancels its pending change. SELECT, ALGORITHM and REC are inert here. Style commits use the selected timed transition for generated sources. Manual notes/patches remain literal.
- LFO dot follows the real DSP phase, at the chosen frequency/shape; S&H uses its actual held value. Fast oscillation is sampled at display refresh. FX graphics show the actual send/routing or a control-response diagram, not an audio meter or measured spectrum.
- PATTERN REC captures the generated pitched 16-slot phrase and arms **silent selected-step entry**. SELECT chooses an edit slot; keys write that slot and advance the cursor. Entry never auditions immediately, stopped or playing. The sequencer plays the note on its next scheduled visit. REC stops entry. Existing manual slots remain. The current format stores one note per pitched step; a generated chord contributes its first melody note. Drums use SELECT for lane and white keys for 16 step toggles. On a manual pitched pattern, ARP clears the SELECTed slot; the sequencer releases a Texture voice when it reaches an empty slot. Keys still enter silently.
- PATTERN's **amber marker / PLAY number** is the actual layer step, respecting SPEED and swing dispatch, including rests. It is a clock position, not a note-on/audio-level meter; envelopes and echoes sound between steps. The **thin green marker / EDIT number** is the selected entry slot. The page updates at up to 20 Hz. EDIT or SEQ again toggles MANUAL/AUTO without deleting manual edits; toggle back to reuse them. REC from AUTO captures a fresh phrase.
- LAYER EQ is one SCL press after FX. LOW/MID/HIGH/OUTPUT each cover −12…+12 dB. Broad fixed splits are about 180 Hz / 2.3 kHz. Processing precedes dry mix and shared FX sends, including drum image/per-lane sends. Each track has independent state/gains; flat EQ is exact bypass, changes smooth, high boosts have a bounded headroom knee. Master EQ remains separate.
- Texture: fresh patches use sustained NOISE, 100% activity and AUTO STEADY mode, which holds a continuous voice regardless of sparse conductor events. PULSE/DRIFT/BURSTS/SPARSE modes allow gated texture activity. Sound changes reset fresh Texture recipes to STEADY. High Air and Distant Hiss replace the pitched Glass Wind/Distant Voices factory recipes. Saved old PHASE patches retain their original names/parameters; choose a fresh Texture patch for the revised palette.
- PRESETS browses eleven factory pieces then eight user slots. After a confirmed choice the knob continues from that position. REC recalls at the next bar during PLAY; HOME cancels. Replacing sounding tracks uses the bounded old-release handoff. Recall does not save.
- SAVE: stop playback, SELECT a slot, REC saves an empty slot. Occupied slots need REC twice; SELECT/HOME cancels overwrite. No fabricated date. Failed writes retain the previous CRC-verified A/B copy. Unsupported flash is refused.
- HOME held + SELECT in EDIT changes the edited layer on the same page; the volume target stays at the last HOME choice. HOME + OCT− mutes that target; HOME + OCT+ solos/unsolos it.
- Emulator combinations: hold computer **7** (HOME), then **Z** (OCT−) / **X** (OCT+), or click the corresponding panel button while holding 7. Hold 7 plus left/right for cross-layer editing. The mouse alone holds one control at a time.
- PLAY tap starts/stops; hold 800 ms for emergency output fade. A later tap reopens the output. ENV/LFO/FX/SEQ/ARP are layer shortcuts; OCT± normally shifts keyboard octave. LEDs indicate available actions; pending REC confirmations breathe, recording REC stays solid.
- Interaction guidance is always in the same three-line footer: navigation, context actions, then notices/pickup/status. Matching font, color, uppercase casing and alignment. Page bodies hold data and diagrams; pickup does not hide action hints.

## Choir, ensemble and help

- In EDIT → SOUND → PATCH, turn SELECT past the original eight Pad or Drone sounds. Pad 9–11 are Open Aah, Round Ooh and Plainchant. Drone 9–11 are Low Ooh, Chapel Aah and Cantus. These use JIANT VOICE. The four SOUND controls shape the starting vowel, glottal buzz, breath and formant shift. EDIT opens the second vowel, morph time, resonance and randomness. On HOME, VOWEL offsets the starting vowel.
- The new PRESETS entries follow Night Garden. Window Seats is a 58 BPM D-major piano miniature with Ooh, chip drone and harp. Stone Cloister is a D-Dorian vocal line over a low Ooh pedal with harp and air. Both leads start in AUTO. On Stone Cloister the Pad PATTERN mode CHANT generates a new contour for each phrase, with a reciting tone, neighboring notes and a cadence. Factory recall starts a fresh take. A saved user piece keeps its seed and any recorded MANUAL steps. Tidal Loom pairs evolving FLOAT synthesis with Porcelain and reed bass in F Lydian. Kite Strings is an A-major harp and soft organ piece with a Euclidean pulse.
- Press SCL on HOME for ENSEMBLE. HOME held + SEQ also opens it from another page. Each row shows that layer's post-level mixer peak and voice state. NOTE is a gated voice, REL is its release, TAIL is a pending sound change, and REST is an idle source. Shared reverb and echoes can continue during REST. Knobs 1–4 directly mix L1–L4. Changing the gain assigned to physical MASTER re-arms pickup. SCL or HOME returns to HOME.
- Hold HOME and press EDIT for the current page's knob guide. In the desktop emulator, hold **7** and click **EDIT** on the panel. Tap HOME to return to the same page. The four encoders do not edit while reading help. PLAY still controls transport.
- Manual pitched PATTERN exposes STEP, SPEED, NOTE and VELOCITY. A positive NOTE turn on a rest inserts a note from the current voicing. ARP clears it. For manual Drums the knobs select step and lane, set a hit or rest and adjust swing. In AUTO STEADY Texture the controls are mode, noise colour, drift and filter cutoff.
- Drum ENV exposes hit decay, tone, FM attack and noise. Its SOUND → DETAIL → PLAY knobs mix the four sequenced drum voices. Sample ONE-SHOT ENV exposes start, end, gain and edge fade. Analog FX cutoff edits the synth's own filter. On a generated chord the PLAY group offers chorus amount alongside glide, transpose and pan.

- Departure Hall follows Kite Strings in PRESETS. It opens at 54 BPM in C major using C, D, E, G and A. Two felt pianos play in different registers on five- and eleven-step cycles. Round Ooh and Cedar Triangle enter on their own cycles. GLO → GENERATE starts on ODD LOOPS. HOME's lit keys edit the pitch pool for all four parts.
- In a Pad layer's SOUND page, SELECT chooses Glass Haze at position 4. Amber Brass, Cedar Triangle and Umber Pulse are positions 14–16. On HOME, WARMTH closes the low-pass filter as you turn it up. On SOUND, DETUNE sets the oscillator separation and CUT opens the filter directly.
- Old user slots containing FM Glass Haze play those saved parameters. To hear the revised sound, select a neighboring Pad patch and turn back. Load the factory Stone Cloister to hear the new chant. A previously saved manual performance still plays its original notes.

Save **v4 is 1420 bytes**, within the existing 3840-byte A/B capacity and unchanged eight-slot sector bounds. v1–v3 1400-byte records migrate with flat layer EQ and a 3000 ms cap. Older pre-v4 firmware cannot read v4; v0.5 may reject new Noise Texture recipes 2/4. New recipe indices above 7 also require v0.7. The new Pad IDs, revised Glass Haze and CHANT mode require this checkpoint to recall reliably. Preserve old pieces/exports and separate emulator state for rollback.

The pinned HAL/emulator model knobs 1–4 as quadrature encoders; only MASTER is an absolute ADC pot. No analog wiring or external input was invented. The generic absolute selector decoder remains separately tested.

## Garden and Tono sounds

- Select **Garden** with PRESETS and confirm with REC. It starts in D Dorian at 72 BPM. In another piece, choose GLO → GENERATE → RHYTHM → GARDEN to use its timing and pitch choices with that piece’s current layers.
- On EDIT → SOUND, Pad has Garden Rhodes, Sunroom Keys and Linen Pad. Drone has Skylight. Bells has Garden Bell, Willow Tine and Dew Bell. Bass has Garden Pedal and Linden Bass. Drums has Garden Pulse. Turn SELECT on the PATCH page to switch sounds.
- In GLO → MASTER FX choose PLATE on the reverb bank or SHORT ECHO, TWO HEAD or ECHO+TAPE on the delay bank. The layer sends and shared return controls set how much you hear.
