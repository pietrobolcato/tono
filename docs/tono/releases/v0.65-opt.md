# Tono v0.65-opt

First public release. This combines the accumulated changes since the early 0.44 builds.

- Garden opens at startup. The factory bank includes the ambient, jazz, acid, piano and A22 arrangements developed since then.
- Generate offers factory and user recipes. Phrase styles include Markov Walk, Drift and Acid Line. HOME density works for the entire mix and for individual layers.
- Auto Travel can evolve the arrangement, generator recipe and layer types. HOME + ALGORITHM opens the layer evolution chooser. HOME + LFO links the last layer control.
- Sample playback includes acoustic instruments, field recordings and speech. Personal takes can be captured using USB audio input.
- Dieter uses the rotary dial at startup. TE Dark and TE Light use accent meters, with a slowly rotating HOME ring during playback. The last saved theme applies at boot.

See the [installation and recovery guide](../INSTALL.md). For the tested UC25HQ80 upgrade from 0.57-opt, the simulated installer wrote 143 application sectors. A song saved in 0.57 was recalled byte for byte in 0.65. The release passed a 1,643-frame native layout audit. This build had focused emulator boot, theme, storage and download-mode checks. The longer performance run in the 0.62 release is historical evidence.

The release contains the FM-SWITCH firmware, source, provenance, checksums, licence notices and a separate macOS ARM64 emulator bundle.
