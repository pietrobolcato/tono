# Contributing to Tono

Open an issue with the Tono version shown at startup, exact steps to reproduce and whether you used hardware or the emulator. For hardware issues, include the flash variant if known. Share project files or audio only when you want them to be public.

Use the [build guide](docs/tono/BUILD.md) and [contributor instructions](AGENTS.md). Keep one behavioral change per pull request where practical. Describe the checks you ran and link any renderer or emulator evidence. For interaction changes, follow the [controls guide](ambplus/CONTROLS.md).
