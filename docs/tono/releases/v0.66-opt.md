# Tono v0.66-opt

Status messages now appear as a centered strip at the bottom of the screen in all three themes. A message can briefly cover a shortcut while the screen layout stays fixed. The shortcut reappears when the message clears.

You can now [play Tono in your browser](https://pietrobolcato.github.io/tono/). Click Start to boot the release firmware, then PLAY to hear Garden.

The release includes the firmware for FM-SWITCH, matching source and a macOS ARM64 emulator. See the [installation and recovery guide](https://github.com/pietrobolcato/tono/blob/v0.66-opt/docs/tono/INSTALL.md).
