# Tono Help screens

Hold **HOME** and press **EDIT** from the screen you want to learn. Turn **SELECT** to move through its guide. Press **HOME** to close Help and return to the same screen. The guide uses the same button and knob caps as the footer.

The first page explains the screen. Other pages explain the assigned controls, their setting ranges, and what their choices do. For example, Generate lists its rhythms, phrases and interplay choices by name, and LFO explains waveforms, rate modes and modulation targets. Turn SELECT while reading to browse the manual without changing the song.

| Where you open Help | What the guide covers |
|---|---|
| HOME / Master | Mix, live travel and shared HOME shortcuts. The second bank offers Low EQ, Echo, Mid EQ and Tempo |
| HOME / Layer | Layer shortcuts for mute, solo, sound lock, LFO linking and evolution. The second bank depends on the selected role |
| Ensemble | Activity states, individual layer levels and return to HOME |
| Zen | Contour and Train Ride, landscape changes and return to HOME |
| EDIT / Mode | Layer roles, sound editing, source replacement and layer macros |
| EDIT / Sound | Factory sounds, patch previews and the steps for applying one |
| EDIT / Sample | Source, Playback, Character and USB capture |
| EDIT / Sound detail | Engine, Filter and Play controls. Drum kits also explain their individual voice levels |
| EDIT / Envelope | Attack, decay, sustain and release, with separate explanations for drum hits and sample one-shots |
| EDIT / LFO | Waveform, speed, depth and modulation destination |
| EDIT / LFO Rate | Fixed or random timing, rate limits and beat-synced durations |
| EDIT / Pattern | Automatic generation and manual steps, with pitched, drum, texture and mono editing behavior |
| EDIT / FX | Drive, chorus and pan, delay send, reverb send, spatial controls and granular processing |
| EDIT / Layer EQ | Low, middle and high bands and output trim for the selected layer |
| GLO / Evolve | Slow changes to harmony, timbre, rhythm and effects |
| GLO / Harmony | Key, scale and tempo |
| GLO / Generate | Rhythm, phrase, interplay and variation, with factory and user recipes |
| GLO / Master FX | Shared reverb, delay and tape, motion and warmth |
| GLO / EQ | Low, middle and high bands and output trim for the master mix |
| GLO / Theme | Studio Dark, Studio Light and Dial |
| GLO / Travel | Journey style, bounded or endless movement, tail time, handoff and Auto |
| GLO / Travel Timing | Movement clock and reach, pattern changes, and layer-type changes |
| SAVE | Choose a user slot, capture a song and confirm replacement if a song already occupies the slot |
| Song preview | Launch a fresh factory take or recall a user arrangement |
| Preset and Generate dialogs | Browse, apply or store a page preset or Generate recipe |
| Chord, Role and Sound proposals | Confirm what changes in the harmony, layer role or patch and when it takes effect |
| Layer evolution and restore | Apply the Travel rules to a selected layer or restore its settings from the last loaded song |

The numbered knob cards follow the active context. Available cards depend on the current role, engine, effect module and edit mode. See the [control card](../../ambplus/CONTROLS.md) for the full control reference.

On Generate, Interplay shows four numbered layer lanes. Each column summarizes a quarter note in an illustrative pattern. Tide Together has its own view of the full twelve-bar cycle. The first eight bars follow the shared density envelope, then all layers rest for four bars.
