## Required complete musical functionality (not just UI)

### A — Four independently configurable audio layers and performance HOME
- Four actual simultaneous layers; each may be assigned **PAD, DRONE, BELLS, BASS, DRUMS, TEXTURE or SAMPLE**. MASTER is a fifth **control target**, NOT a fifth voice.
- Selected HOME target cycles via **SELECT rotary only**: MASTER → L1 → L2 → L3 → L4. SEL does NOT select HOME layers; SEL cycles page screens inside EDIT/GLO.
- A selected layer has a genuinely working synth voice, level, keyboard response, mute/solo, sound patch, local recorded/generative pattern, envelope, LFO, sends and state. The assigned role, not the layer number, determines which engine/pattern UI and playback are used (DRUMS must work in any slot).
- Physical MASTER potentiometer controls master output gain **when MASTER selected**, and only that layer's gain when a layer is selected. Implement absolute-ADC **soft takeover/pickup**, appropriate smoothing, and an always-available emergency global fade/panic independent of selection. Avoid volume jumps and abrupt sound cutoffs when changing targets.
- Knobs 1–4 on HOME are expressive, gain-compensated ambient **macro controls** mapped to the SAME underlying DSP parameters exposed by deeper EDIT/GLO pages. Examples: master SPACE/ECHO/MOTION/WARMTH; pad WARMTH/MOTION/BLOOM/SPACE; contextual musical choices for the other roles. Manual deep edits must be preserved; the macro system adds reversible/bounded modulation around patch baselines, not destructive rewrites.

### B — Complete sound engines and excellent factory content
- Use actually functional, licensed **JIANT synthesis engines** as appropriate (prioritize analog/subtractive, FM bells, string/resonator, noise/textures and DRUM-X, plus additive/voice/phase if sensible and budget permits). Keep sound-engine-appropriate PATCH and DETAIL banks; never show irrelevant parameters (e.g. FM ratio for an analog oscillator).
- Provide **eight curated, genuinely distinct, useful ambient patches per six synth roles (48 patch targets)**, not just renamings of one voice. Target lush pads, slow drones, soft bells, warm bass, delicate percussion, airy textures. Each should sound musical out of the box and respond interestingly and safely to the four HOME macros.
- EDIT's six pages are exactly **MODE → SOUND → ENVELOPE → LFO → PATTERN → FX**; **no MIX page**. On EDIT/MODE, ALGORITHM previews a role, **REC commits** and changes voices with smooth fades; on EDIT/SOUND, **SELECT changes the chosen patch immediately** without REC, and EDIT cycles PATCH/DETAIL banks. The four numbered knobs change technical settings immediately. ENVELOPE has slow ambient-friendly attack/release, LFO has genuinely slow musical rates, appropriate destinations, safe depth and smooth ramps.
- The SAMPLE role is present and configurable; **microphone/voice input capture can be deferred** (see exclusions), but implement bounded SAMPLE playback from one or more legal bundled example samples if technically feasible: SOURCE / PLAYBACK / CHARACTER banks, a real looper with pitch, blur/motion/space and sensible playback styles. Where sample capture is absent, label it unavailable rather than pretending it works. Do not endanger flash/song storage to squeeze in a sample.

### C — Fully functioning generative music, recording and harmonic evolution
- Port/adapt with verified licensing the musical core ideas from **AMB-1**: evolving shared chords and tasteful voice-leading, different compatible per-layer notes/chord voicings, long phrases, unequal-length loops, sparse Euclidean percussion and relaxed generative melodies. Pad/drone/bell/bass parts should complement one another rather than all play identical block chords; drums and patterns remain editable.
- **ALGORITHM** on HOME or GLO/EVOLVE browses compatible harmonic destinations and displays a short, human-readable expected mood descriptor such as warmer / darker / brighter. Browsing doesn't change audible harmony. **REC commits** the visible destination, immediately when stopped or at a bar boundary when running. Keep the configured key/scale unless deliberately changed on GLO/HARMONY. Do not create pitch jumps/clicks; preserve common tones and long releases.
- GLO/EVOLVE: independent HARMONY/TIMBRE/RHYTHM/FX evolution amounts on Knobs 1–4; SELECT chooses auto evolution OFF/1/2/4/8/16/32/64 bars. Manual evolution remains available with AUTO on. Critically, generated timbre/effects/rhythmic evolution applies **non-destructive, bounded offsets**, never destructive changes to saved patch settings or manually recorded patterns.
- The unified **GLO/GENERATE** page has 8 RHYTHM strategies, 8 PHRASES strategies and 6 INTERPLAY strategies defined in `GLOBAL_GENERATORS.md`, chosen with absolute physical Knobs 1–3; Knob 4 is VARIATION. Default = AMB DRIFT / AMB BREATHE / BLEND. These are **22 distinct functioning light-weight event-scheduling policies**, not fake graphics or 22 DSP synths. Use ADC pickup, discrete-choice bins, hysteresis and final-settle; queue live switches for the next shared four-bar transition. Three tiny screen graphics reflect each selected strategy. Manual notes/drums, sample source, envelopes, LFOs, patches, FX and layer volumes must be unchanged by global generator selection. SELECT has no action on GENERATE.
- EDIT/PATTERN supports real step recording with REC, playback, individual drum lane selection using SELECT, editable 16-step rhythms, swing/density/fills/mutation and functional pitched melody/arpeggio patterns. Correctly light available scale keys while pitched REC is active; indicate current root and pressed note; do not block intentionally off-scale notes. Global generation must not alter manual locked patterns. FOLLOW/role behaviour belongs here, not in a MIX page.

### D — Complete ambient spatial effects and master output
- Integrate/select appropriate licensed JIANT and AMB processing to make the instrument ambient-first: actual shared high-quality **reverb**, delay/tape-echo/long-loop where feasible, per-layer effect sends, soft drive/saturation, optional gentle chorus/modulation, stereo placement and master EQ/output protection. Prioritize long smooth tails, warmth, low noise, click-free parameter motion and headroom; avoid duplicating expensive reverb engines simply to fill menus.
- EDIT/FX contains per-layer modules (drive/chorus/delay/reverb/SPATIAL or justified efficient equivalents), including sends and pan. GLO/MASTER FX controls shared FX algorithms/parameters. HOME MASTER macro settings must mirror the same real effect state; a layer with small send stays comparatively dry. Preserve tails when muting, switching patches/modes or changing effect settings as much as resource budgets permit.

### E — Complete UI, LEDs, persistence and usability
- Port the 240×240 **Phosphor** UI into JIANT's native display renderer and actual device input/event system; all text and helper badges must be legible at 240px with no overlap or duplicate instructions. No fake clickable web control mapping: use the actual FM1 buttons, LED matrix, rotary encoders and absolute potentiometers. Button LEDs illuminate only when pressing them would have meaningful action now; **REC pulses when visible commit is pending**, stays solid during actual step recording. Knobs cannot physically light.
- EDIT six pages above; GLO uses EVOLVE / HARMONY / GENERATE / MASTER FX / EQ (**VISUAL deferred**). SEL cycles pages, SELECT navigates context. MODE changes preview/REC; patch selection immediate; step REC is recording (not a freeze toggle). HOME+SELECT cross-layer editing shortcut where it does not conflict; support a trackpad-friendly emulator interaction if needed. SAVE and PRESETS keep their distinct assigned responsibilities.
- Factory ambient compositions, plus **eight user save slots as a target**, subject to a proven flash-storage budget. PRESETS previews saved pieces and REC confirms recall; SAVE opens destination selection via SELECT, then REC writes an empty slot or requires **double REC for an occupied slot**. Changing slot or HOME cancels overwrite. Persist whole instrument state, effects, global conductor and patches, and implement versioned save/migration/CRC recovery. Never fabricate calendar timestamps without a valid clock source. If eight safe slots cannot fit, give measured options and document that blocker—never corrupt flash to satisfy a number.
- Provide working PLAY/STOP, panic fade, mute/solo, memory-safe startup, deterministic reset/default piece, patch changes without clicks, full keyboard scale cues and sensible saved defaults.
