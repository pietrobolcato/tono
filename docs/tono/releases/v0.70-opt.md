# Tono v0.70-opt

**Two LFOs per layer.** Press LFO to open the layer’s modulator, then press it again to switch between LFO 1 and LFO 2. Each has its own waveform, rate, depth and destination. Set depth to **Off** to silence either lane. Generic new sounds start with modulation off. Sounds authored with modulation keep their programmed movement.

**See what the filter does.** The synth Filter page and the Layer Filter in layer FX show the live spectrum with the filter response drawn over it. The layer filter processes the whole layer. In **GLO → Master FX → Limiter**, set the ceiling and release while watching the stereo input peak, output peak and gain reduction.

**Start a sound with its own settings.** Confirm a new sound or layer role to start with its intended effects and HOME macros. In the Sound browser, turn ALGO past the last named sound to **Auto**, then press REC to let Tono choose a sound for the arrangement.

Open context Help with **HOME + EDIT** for the controls on each page. Turn SELECT to read the next section.
