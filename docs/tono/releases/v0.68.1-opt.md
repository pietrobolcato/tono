# Tono v0.68.1-opt

HOME Help gives held-HOME knobs, performance shortcuts and layer shortcuts their own pages. Select a layer to see its mute, solo, sound lock, LFO and evolution shortcuts.

In EDIT → Mode, open Help and turn SELECT once for a practical guide to the active role. Keep turning to browse all eight roles. Warmth explains what you hear as you raise it. Control pages use a middle divider when there is a second section to read.
